# SP Downloader

**یک مدیریت‌کنندهٔ دانلود رایگان، متن‌باز و self-hosted.**

لینک را بچسبان — خروجی بگیر: MP4، MP3، یا خودِ فایل.
صفحات ویدئویی، صوت، دانلود مستقیم و آرشیوهای چندتکه، همه از یک رابط وب تمیز،
همراه با تاریخچهٔ قابل‌جستجو و پروکسی قابل‌تنظیم.

</div>

## چرا SP Downloader؟

- **کاملاً رایگان و متن‌باز.** با لایسنس MIT. بدون حساب کاربری، بدون telemetry،
  بدون نسخهٔ «pro» پولی. روی سیستم خودت اجرا کن، دیتای خودت مالِ خودت.
- **یک رابط برای همه‌چیز.** یک کادر لینک، هم ویدئو، هم صوت، و هم فایل مستقیم را
  مدیریت می‌کند — برنامه خودش تشخیص می‌دهد چه دادی.
- **وابسته به هیچ پلتفرم خاصی نیست.** روی
  [`yt-dlp`](https://github.com/yt-dlp/yt-dlp) سوار است و با بیش از ۱۰۰۰ سایتی که
  yt-dlp پشتیبانی می‌کند کار می‌کند، به‌علاوهٔ هر آدرس مستقیم `https://…/file.ext`.
- **تاریخچهٔ واقعی.** هر دانلود ثبت می‌شود، با فیلتر وضعیت/نوع/منبع، و بعد از کرش
  یا ری‌استارت قابل ادامه است.

## امکانات

| | |
|---|---|
| 🎬 **ویدئو** | انتخاب کیفیت، خروجی MP4 ادغام‌شده. |
| 🎵 **صوت** | استخراج مستقیم به MP3 با بیت‌ریت دلخواه. |
| 📦 **فایل** | دانلود مستقیم آرشیو، نصب‌کننده، سند، تصویر، فونت… و تشخیص و گروه‌بندی خودکار **آرشیوهای چندتکه** (`file.part1.rar`، `file.7z.001`، `file.z01` و…). |

| ⏸️ **توقف · ادامه · تلاش مجدد** | دانلود نیمه‌کاره از روی فایل ناقص ادامه پیدا می‌کند، نه از صفر. |

| 🍪 **کوکی مرورگر** | در صورت نیاز، از نشست لاگین‌شدهٔ مرورگرت استفاده کن. |

| 🌗 **PWA با تم** | راست‌به‌چپ، روشن/تیره/خودکار، قابل‌نصب. |

## شروع سریع

### پیش‌نیازها

- **[Node.js](https://nodejs.org/) نسخهٔ ۱۸ یا بالاتر**
- **[FFmpeg](https://ffmpeg.org/download.html)** روی `PATH` (برای ادغام ویدئو+صدا و تبدیل به MP3)
  - ویندوز: `winget install Gyan.FFmpeg` · مک: `brew install ffmpeg` · دبیان/اوبونتو: `sudo apt install ffmpeg`
- MongoDB **اختیاری** است — بدون آن، تاریخچه در یک فایل JSON محلی نگه داشته می‌شود.

### نصب و اجرا

```bash
git clone https://github.com/AmirHaddadi/SP-Downloader.git
cd SP-Downloader
npm install

# دریافت هستهٔ yt-dlp مخصوص سیستم‌عاملت در ./bin
npm run update-core

# اختیاری: ساخت .env (همهٔ مقادیر پیش‌فرض معقول دارند)
cp .env.example .env

npm start
```

آدرس **http://localhost:4000** را باز کن و یک لینک بچسبان.

## تنظیمات

گزینه‌های زمان اجرا در پنل **تنظیمات** رابط کاربری هستند و در
`~/.vdl_config.json` ذخیره می‌شوند: پوشهٔ دانلود، تفکیک خودکار، کوکی مرورگر،
و پروکسی (`http://user:pass@host:port` یا `socks5://host:port`).

گزینه‌های سطح سرور در `.env` — به [`.env.example`](.env.example) نگاه کن.

## مسائل حقوقی

SP Downloader یک ابزار عمومی است، مثل مرورگر وب یا `wget`. مسئولیت داشتن حق
دانلود هر محتوا و رعایت قوانین سایت‌ها و قوانین محلی بر عهدهٔ **خودِ کاربر**
است. نگه‌دارندگان پروژه از نقض کپی‌رایت حمایت نمی‌کنند.
