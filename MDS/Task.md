قبل از هر کاری، اسکیل sp-downloader-protocol رو کامل بخون و طبق همون عمل کن. کامیت نزن، توضیح اضافه نده، فقط کد/دیف بده.

سه تسک زیر رو به‌صورت یکپارچه روی پروژه‌ی SP-Downloader انجام بده:

1. دانلود بچ چندلینکی + تشخیص فرمت + گروه‌بندی به‌صورت "پک"
- کاربر باید بتونه چند لینک رو هم‌زمان (هرکدوم در یک خط) داخل سرچ‌بار پیست کنه.
- سیستم باید همه‌ی لینک‌های معتبر رو پارس کنه، برای هرکدوم متادیتا/پلتفرم/فرمت رو مثل روال preview فعلی شناسایی کنه (از همون endpoint /api/meta موجود استفاده کن، به‌صورت موازی/queue-شده، نه سریالی کند).
- همه‌ی این آیتم‌ها باید زیر یک شناسه‌ی مشترک "پک/بچ" گروه‌بندی بشن (یک batchId که در state سرور و در UI صف نگه‌داری میشه) — نه به‌عنوان آیتم‌های پراکنده‌ی بی‌ربط به هم.
- کاربر باید بتونه از داخل همون پک: تک‌تک آیتم‌ها رو انتخاب/دیسیلکت کنه، یا با یک کلیک "دانلود همه‌ی پک" بزنه.
- این کاملاً فول‌استک باید انجام بشه: ساختار state سرور (Map دانلودها) باید مفهوم batchId رو پشتیبانی کنه، پاسخ meta/download و پیام‌های SSE باید batchId رو برگردونن، و UI باید پک‌ها رو به‌صورت یک بلوک قابل‌جمع‌شدن (mنمایش گروهی + progress کلی پک) رندر کنه.
- خط‌قرمزهای بخش ۲ اسکیل (لودینگ هر آیتم، خالی/خطا برای پک، انیمیشن سبک روی اضافه/حذف آیتم از پک، ریسپانسیو، RTL) اجباریه.

2. بازطراحی اختصاصی سرچ‌بار
- استایل/ظاهر سرچ‌بار باید مدرن‌تر و اختصاصی‌تر از الگوی input ساده‌ی فعلی بشه؛ ولی از دیزاین‌توکن‌ها و رنگ‌های موجود پروژه استفاده کن، پالت جدید اختراع نکن.
- افکت placeholder به‌صورت تایپ‌استریم پیاده بشه: متن به‌صورت حرف‌به‌حرف رو به جلو تایپ بشه و بعد رو به عقب پاک بشه (typewriter/erase loop)، با یک커‌سر/نشانگر چشمک‌زن که همراه متن حرکت می‌کنه — پرفورمنس این افکت باید سبک باشه (JS ساده با setTimeout/rAF، بدون هیچ کتابخانه‌ی خارجی جدید).
- محتوای این متن‌های چرخشی باید از پیش تعیین‌شده و مرتبط با پلتفرم‌ها و قابلیت‌های واقعی پشتیبانی‌شده‌ی پروژه باشه (یعنی جملاتی مثل نمونه‌ی لینک یوتیوب/تیک‌تاک/اینستاگرام/توییتر/ویمیو و مشابه، به همراه اشاره به قابلیت‌هایی مثل دانلود صوت/بچ چندلینکی) — یک آرایه از این متن‌ها در همون app.js تعریف کن و به‌ترتیب چرخشی پخش بشه.
- وقتی کاربر شروع به تایپ واقعی می‌کنه، افکت placeholder باید بلافاصله متوقف/مخفی بشه و به رفتار عادی input برگرده، بدون تداخل بصری.
- این تسک کاملاً فرانت‌اِند است، به سرور کاری نداره.

3. رفع دقیق ارورهای زیر در public/style.css (بدون دست‌زدن به بقیه‌ی فایل)
- خط ۹۹۱: یک ruleset خالی وجود داره (emptyRules) — یا selector رو حذف کن یا اگر placeholder عمدی برای توسعه‌ی بعدی بوده، به یک کامنت CSS تبدیلش کن، نه یک بلاک `{}` خالی.
- خط ۴۷۰: از `-webkit-line-clamp` استفاده شده بدون property استاندارد `line-clamp` — همون property استاندارد رو هم اضافه کن (با همون مقدار) تا سازگاری کامل باشه.
- خط ۳۱۷: از یک vendor-prefixed `mask` (مثل `-webkit-mask`) استفاده شده بدون property استاندارد `mask` — همون رو هم با همون مقدار اضافه کن.
- فقط همین سه خط رو فیکس کن، رفاکتور یا تمیزکاری اضافه‌ی کل فایل ممنوعه (scope creep).
